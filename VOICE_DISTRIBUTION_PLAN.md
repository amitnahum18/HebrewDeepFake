# Voice distribution analysis plan — 2026-11-17

This extends prior full-corpus audits with actual speaker embeddings, not new TTS. No paid API calls, human labels or source changes.

1. Use an isolated project Python environment for compatible CPU PyTorch/SpeechBrain. Download the official `speechbrain/spkrec-ecapa-voxceleb` embedding weights and hyperparameters at a pinned revision; hash both. Use official Fbank/sentence normalization/ECAPA layers and L2-normalize embeddings. Do not use speaker-class logits, gender/age inference, or a default identity threshold.
2. Select up to three qualified 3–8 s real utterances per eligible speaker (6–14 words, source and segment scores >=0.8, valid in-bounds timing). Prefer distinct sessions and normalized texts, then duration near 4.5 s. Record selection and coverage including source IDs with no eligible excerpt. This is a balanced identity sample, not corpus-hour or population-representative sampling.
3. Extract real intervals as mono16k PCM16 and verify decoded coverage. Initial PTS-based extraction exposed packet timestamp jitter: treating each small gap as missing samples would insert artificial zeros and exclude many valid voices. Therefore use the concatenated decoded sample clock, consistent with preceding EDA, with no inserted silence. Preserve the initial attempt manifest as a diagnostic; fail closed for >2% unavailable decoded samples. Human boundary validation remains pending. Synthetic clips use existing saved WAVs.
4. Extract embeddings for original boundaries and an independent analysis-only capped edge-quiet trim (<=0.25 s per side, same absolute -45 dBFS rule for both labels). Never overwrite canonical originals. Check real same-ID versus different-ID cosine distributions, separately reporting cross-session support before interpreting coverage.
5. Compare: within-ID consistency, between-ID diversity, cross-class nearest neighbours, model-version consistency, family-balanced and identity-balanced distributions. High similarity is a listening candidate, not identity/duplicate proof. Count nominal voices conservatively across model versions.
6. Compute descriptive high-dimensional distances (cosine distances and biased RBF MMD at fixed median-distance bandwidths), with equal identity weighting and sensitivity to equal family weighting. Any label-permutation result would concern exchangeability of this selected sample, not synthesis causality; do not claim population significance. No detector trained.
7. Plot ECDFs of distances, shared PCA/t-SNE projections, nearest-neighbour coverage and robust-scaled acoustic-feature comparisons. Projections illustrate, while distances are computed in original spaces. PCA/t-SNE appearance does not establish equality/difference of distributions. Robust scaling uses pooled observed group medians; report native-unit marginal effects separately from the preceding EDA.
8. Assess selection coverage versus source sex/age metadata without deriving demographic labels from embeddings. Text, phonetic composition, codec history and reference extraction still confound real/synthetic classes; same-text pairs are future work.
9. Execute a notebook, produce CSVs/figures and a Hebrew results report, verify hashes, finite unit-norm vectors, identity accounting, pair definitions and notebook errors. Model inference is cached; notebook analysis reruns offline from saved vectors.
